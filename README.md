# 沖繩悠遊 5 日 · 4 夜

手機優先的單頁靜態行程網站，旅程為 **2026/10/05–10/09**。保留每日時間軸、資訊分頁、翻牌時鐘、「回到現在」與版本更新提示；無框架、無 npm 依賴、無建置需求。

## 資料來源與限制

行程依 **京王國際旅行社《沖繩悠遊5日》旅遊手冊**整理。公開網站僅包含行程及實用資訊，不收錄旅客姓名、私人電話、分房名單或來源 PDF。手冊時刻是參考安排，實際以導遊、當地確認、天候、交通及航空公司通知為準。

- 四晚皆住 Daiwa Roynet Hotel Naha Omoromachi（那霸歌町大和ROYNET飯店）。
- 全團人數未知，不設定 `meta.people`；Day 3 浮潛 7 名僅是活動參加人數。
- Day 4 全日自由活動、無團體旅遊車；國際通、新都心／DFS、ASHIBINAA 只是自選建議，不是確認行程。
- 餐食依手冊保留；Day 2 蝦蝦飯專門店是停留點，包含午餐為 INO 自助餐。
- 行李、氣候、免稅與其他旅遊提醒為手冊參考，不代表已核實最新規則或即時預報。

### 時間規則

- `meta.timezone` 為 **`+09:00`（日本）**，時間判斷不得依賴裝置時區。
- 手冊原有時刻保持不變；依使用者要求補上的概略時間使用 `timeEstimated: true` 與「預估／時間僅供參考」標籤，不代表已確認集合時間。
- Day 4 時段是自由活動參考安排，景點仍為自選，不能把所有備選點視為必走路線；高亮只反映參考時段。
- 台灣集合與航班時間必須換算日本時間供判斷，但以 `timeLabel` 明確保留台灣時間：集合台灣 07:00 → 日本 `08:00`；CI310 起飛台灣 10:00 → 日本 `11:00`；CI311 抵達台灣 14:10 → 日本 `15:10`。
- Day 3 浮潛結束 `16:30` 是手冊預計時刻，顯示標籤與說明必須保留「預計」及天候／教練限制。

### 地圖與圖片

導航採 Google Maps **HTTPS `api=1` 關鍵字搜尋**，不是精確路線保證。`coords` 保持空物件，不加入猜測座標；未指定的餐廳分店或地址不得自行補入。圖片僅使用已確認地點與授權的來源；相關但非確切景點的照片，必須在 `imageCaption` 清楚標示「示意」。`image: null` 或載入失敗時使用抽象海岸紋理與旅程筆記，不假裝是地點照片。

照片說明、作者及來源不在景點卡片展開；必要出處與完整授權集中在頁尾連結的 `photo-credits.html`。示意或周邊照片只保留簡短標示，完整替代文字仍保留給輔助技術。

`js/maps-launch.js` 捕捉有效 Google 地圖連結：手機優先喚起 Google Maps（iOS scheme、Android 指定套件 intent），無法喚起時提供 HTTPS 網頁備援；桌面維持一般連結。Telegram 等內建瀏覽器及作業系統仍可能要求確認或攔截 App 喚起，不能保證網頁能偵測是否安裝 App。

## 本次行程工具與離線使用

- 頁首「返飯店・電話・地址」：飯店地圖、公開電話、複製地址，以及給司機看的日文句子。飯店為原 Omoromachi 館，並非 Premier 館。
- 每日餐食與重要提醒：區分團費包含與自理餐食、Day 3 青洞參加／未參加者分流、Day 4 無團體車的自選路線，以及 Day 5 退房與機場安排。
- 資訊頁提供官方天氣、颱風、華航航班動態、Visit Japan Web 與緊急協助連結；不把靜態手冊內容當作即時預報或最新政策。
- 行李清單只在本機保存勾選狀態，支援同源分頁同步。拒絕 localStorage 的環境仍可使用，但無法保證重開後保留。
- 第一次連網開啟後，需看到「本站離線內容已完整儲存」才能放心離線使用。此時可離線查看五日行程、36 張卡片照片、實用資料與清單；外部導航、即時天氣、航班與入境申報仍需網路，電話需電信訊號。
- Service Worker 只快取 `offline-assets.json` 列出的本站公開檔案；不儲存第三方頁面、私人資料或任意 URL。CI 為 `index.html` 與 `sw.js` 同時印上版本。更新不強制重載，以免閱讀中斷。

### 照片來源與限制

36 張行程卡涵蓋 23 個地點關鍵字，共用 21 張本地照片。來源、作者、授權、變更與檔案 SHA-256 記錄在 `data/photo-sources.json`，卡片亦顯示來源；圖片縮放至最長邊 1280px 並壓縮為 JPEG，本地衍生圖片沿用來源授權，不由程式碼授權覆蓋。

蝦蝦飯、EBISU 與五苑未取得可重用的確切店家照片，使用明確標示的料理示意；INO 使用園區照片、琉球工房使用美國村周邊、青洞使用真榮田岬周邊，均不冒充餐廳內部或洞內照片。部分照片為歷史街景，不能據此保證當前店面外觀。

### 仍需現場確認

青洞實際集合點與接送安排、未定時景點的集合時間、未指定餐廳的分店，以及自由日交通、費用與營業狀況，仍以導遊、店家與官方即時通知為準；網站不自行補寫成已確認事實。

## 本地預覽與驗證

在專案根目錄執行：

```bash
python3 -m http.server 8000
```

瀏覽 `http://localhost:8000/`。`?now=` 覆寫是**日本當地時間**，例如：

- 旅程前：`http://localhost:8000/?now=2026-10-04T20:00`
- 行程中：`http://localhost:8000/?now=2026-10-06T13:00`
- 全日自由活動：`http://localhost:8000/?now=2026-10-08T14:00`
- 旅程後：`http://localhost:8000/?now=2026-10-10T09:00`

```bash
python3 -m json.tool data/itinerary.json > /dev/null
for file in js/*.js; do node --check "$file"; done
node --test tests/*.test.js
```

另以 390px 手機寬度檢查五天與資訊分頁：無水平溢出、無 JS 例外、未定時標籤可讀、航班時區標示正確、地圖連結搜尋正確目的地。
